# NumPy for Machine Learning

A practical NumPy learning repository focused on building the numerical computing skills required for Machine Learning, Data Science, and AI.

This repository follows a hands-on approach:

## Goal

By completing this repository, I should be comfortable using NumPy for:

- Numerical computing
- Array manipulation
- Data preprocessing
- Statistics
- Linear algebra
- Vectorized computation
- Machine Learning algorithms
- Building ML algorithms from scratch
